# WGI 六维与标准误接入方案

## 目标和版本边界

将世界银行 WGI 的问责与表达、政治稳定、政府效能、监管质量、法治、腐败控制六个维度接入现有八国档案，并逐维保留估计值与模型标准误。世界银行已发布 2026 更新并回溯重算历史估计；本轮必须从同一更新版本取得全部十二条序列，不把现有 2025 版三维快照与新版拼接。数据保留官方已发布的 1996—2025 年序列；界面地图年份目前截至 2024 年，故 2025 数值暂不作为可选地图档案。

## 数据结构与同步

沿用现有 `world-bank.json` 的国家、年份、指标代码长表，不把 WGI 估计值转成 CAP。六个维度的指标前缀是 `VA/PV/GE/RQ/RL/CC`，每维保存 `.EST` 估计值与 `.SE` 标准误，不能用未经核对的 `.STDERR`。响应 URL、更新时间、版本、抓取时间、SHA-256、有效条数及空值均须可追溯。标准误必须为非负有限数；估计值不强制限制在 ±2.5。`status` 只表示 API 此格是否有数值，不表示治理事实被直接观测。

同步脚本须先核验 WDI 七指标（包括两项覆盖稀疏的 IMF GFS 财政比率），再核验同一版 WGI 十二指标的国家、年份、代码、页数、重复键和缺失状态，全部成功后才替换文件。WGI 2026 API 目前对八国每项返回 27 年：1996、1998、2000、2002 和 2003—2025；1997、1999、2001 不返回行，不能把它们写成零或插值。源更新时间须与官方 2026 更新相符，防止旧 API 混入；修订旧的“三指标 × 三年”保留逻辑，确保再次同步不会丢弃本轮 WGI。WDI 财政指标仅保留原值，不参与 CAP 自动评分。

## 页面和验收

页面把五项 WDI 与六维 WGI 分区。每个 WGI 维度一行，分别显示“估计值”和“标准误（SE）”；任一值缺失时单独显示横线。说明 SE 不是置信区间，WGI 是基于多来源感知资料的模型估计，不是 CAP 评分或历史实控国界判断。检查 2024 年八国六维配对、早期真实缺口、2025 数据已存但尚无地图档案、SUN 无世界银行借值、关键来源哈希与版本，以及 1937/2024 页面状态。测试与构建统一通过 `scripts/*.sh`，日志写入 `logs/`。

## 已核对的来源

正式代码和版本元数据以 [WGI 官方目录](https://datacatalog.worldbank.org/search/dataset/0038026/worldwide-governance-indicators)、[方法说明](https://www.worldbank.org/en/publication/worldwide-governance-indicators/documentation)及 [API 来源元数据](https://api.worldbank.org/v2/source/3?format=json)交叉确认。2026 更新目录标记 2026-09-18，API 来源元数据更新时间为 2026-09-25；若未来 API 与官方更新版不一致，停止同步并回查同版官方文件，不宣称旧 API 数据为 2026 更新。
