# 真实数据与年份校验

更新：2026-09-19。本轮沿用现有 Vue 2 / ArcGIS 工程，没有安装新依赖；先在 `discuss/cliopatria-integration.md` 记录数据模型和领土关系方案。

## 已接入数据

| 来源 | 当前范围 | 保留方式 |
|---|---|---|
| EIU Democracy Index 2024 | 中国、美国、德国、日本、英国、法国、印度、俄罗斯；总分与五个维度 | 人工核对原报告表 2，保留年份、排名、页码、版本和报告链接 |
| 世界银行 WDI | 上述八国的 GDP、人均 GDP、人口 | 取 1966、1995、2020、2021、2024 年快照，保留单位和指标代码 |
| 世界银行 WGI | 政府效能、法治、腐败控制 | 原始估计值；当前接口 GOV_WGI_*.EST；2025 修订版，不转换为 CAP |
| 《中国的民主》 | 2021-12-04 官方白皮书 | 制度安排、实践和评价视角的简要概述；不生成分数，不向历史年份回填 |
| Seshat ClioPatria | 3400 BCE—2024 的全球政治实体库；本项目使用其中 1900—2024 的 1654 条时段记录 | 生成 27 个目标年份快照，保留名称、时段、面积、Wikipedia、Wikidata、Seshat ID 与关系字段 |
| historical-basemaps | 1900—2010 范围内 10 个实际存在的快照 | 原始文件与修正版分目录保存，两套文件均校验哈希 |
| Wikipedia 年度与历任领导人条目 | 15 个现有国家—年份档案 | 展示国家名、国家元首与政府首脑；同年更替全部列出，保留条目链接和抓取日期 |
| Google Arts & Culture | 1932—1945 满洲国性质说明 | 用于核对日本实际控制与傀儡政权关系，不把满洲国几何并入日本帝国领土 |

世界银行快照共 192 条返回记录，其中 190 条非空、2 条缺失。WGI 未返回的早期年份继续按缺失处理，不伪造额外行。界面现有 15 个档案按国家标识和年份精确取数；未接入的年代保留空白。苏联标识改为 SUN，禁止借用俄罗斯 RUS 的数据。

## 来源

- [EIU 官方版本页](https://www.eiu.com/n/campaigns/democracy-index-2024/)；[原版报告第三方镜像](https://rulesofactivism.com/wp-content/uploads/2025/03/Democracy-Index-2024.pdf)，摘录表 2 第 15、16、20 页。此处有意固定 2024 版，不宣称是最新年度。未把完整报告复制进项目；后续扩大转载范围需遵循 EIU 的数据使用条款。
- [世界银行指标接口说明](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392)；实际查询 URL、源更新时间及抓取时间均保存在 `public/data/observations/world-bank.json`。WDI 源更新时间为 2026-07-13，WGI 为 2026-03-18。
- [WGI 2025 方法修订](https://www.worldbank.org/en/publication/worldwide-governance-indicators)。治理估计值通常约 -2.5～2.5，并非硬性上下界，也不是客观无误的治理等级。
- [《中国的民主》官方全文转载](https://www.spp.gov.cn/spp/zdgz/202112/t20211204_537860.shtml)，发布者为国务院新闻办公室；页面转载来源为新华社。界面明确区分官方自述与独立测量。
- [ClioPatria](https://github.com/Seshat-Global-History-Databank/cliopatria) 提供政治实体名称、有效时段、几何、面积及 Wikipedia、Wikidata、Seshat 标识。本项目固定上游提交并按 CC BY 4.0 署名；几何代表一种历史领土解释，不能单独作为主权裁决。
- [历史底图仓库](https://github.com/aourednik/historical-basemaps)，GPL-3.0，原许可保留在数据目录。空间参考不能替代主权和领土争议的独立考证。
- 领导人资料按国家—年份连接到 [Wikipedia 的 2024 年国家领导人列表](https://en.wikipedia.org/wiki/List_of_state_leaders_in_2024)及各国年度或历任领导人条目。Wikipedia 用于可追溯的初步汇编，后续可继续替换为各国政府档案和权威年鉴。
- [Google Arts & Culture：Manchukuo](https://artsandculture.google.com/entity/manchukuo/m0fctx?hl=en)将其概述为 1932—1945 年存在于中国东北、实际受日本控制且承认有限的傀儡国家；本项目据此将其从日本帝国复合面中拆开。

## 评分边界

原来七个历史档案的合成分数仍保留在原始演示文件中作为旧设计材料，但经过 `buildProfiles` 后不再进入默认地图、雷达和比较。DRI、CAP、NCI 仍是三个独立自定义模型；没有证据和归一化规则时留空。

EIU 原生五维不能无损拆成自定义八维，白皮书也不是可直接相加的数值数据。雷达对 2024 档案显示 EIU 五维；原权重实验仅作用于自定义 DRI，不能改变 EIU 原始评分。散点默认比较同年 EIU 与人均 GDP，缺失点不参与。

GDP 使用现价美元；跨年实际增长分析应另接不变价或购买力平价序列。WGI 未接入标准误，当前不能据细小分差判断统计显著性。

## 运行与校验

所有入口在 `scripts/`，输出在 `logs/`。Windows 使用 `D:/Git/bin/bash.exe` 执行：

```bash
bash scripts/sync-data.sh
bash scripts/check.sh
bash scripts/build.sh
bash scripts/dev.sh --host 127.0.0.1 --port 5173
```

同步脚本使用已安装的 PowerShell 7。先核验 GeoJSON 格式再替换文件，来源失败会中止。测试覆盖 27 个同年快照、禁止未来回退、两套来源文件的校验和、有效时段、Qing 命名、全部目标年份新疆空间归属、1966 年西藏归属、殖民地宗主关系、满洲国傀儡层、争议地区实控层、15 个档案的领导人及来源、EIU 维度范围与平均值、零与缺失区分，以及苏联标识。

2026-09-19 数据验收：27 个 ClioPatria 快照通过哈希、几何、年份区间和专项归属断言；1932、1966、2024 均使用同年面。15 个国家—年份档案均具有领导人文本和来源链接，边界弹窗也显示领导人字段；未逐条核验的实体明确标为待补充。

## 未完成的数据范围

没有完成逐年、逐日国界重建；当前完成的是界面 27 个目标年份的同年快照。全球所有边界面尚未逐国补齐领导人，当前保证 15 个可选择档案均有领导人和来源；其他面明确显示“领导人资料待补充”。历史政治制度的逐维实证评分仍在继续补证。本轮提供可追溯观测，不把单一数据集解释成最终历史结论。
