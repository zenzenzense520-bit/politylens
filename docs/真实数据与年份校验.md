## 评分边界

原来七个历史档案的合成分数仍保留在原始演示文件中作为旧设计材料，但经过 `buildProfiles` 后不再进入默认地图、雷达和比较。DRI、CAP、NCI 仍是三个独立自定义模型；没有证据和归一化规则时留空。

EIU 原生五维不能无损拆成自定义八维，白皮书也不是可直接相加的数值数据。雷达对 2024 档案显示 EIU 五维；原权重实验仅作用于自定义 DRI，不能改变 EIU 原始评分。散点默认比较同年 EIU 与人均 GDP，缺失点不参与。

GDP 使用现价美元；跨年实际增长分析应另接不变价或购买力平价序列。WGI 未接入标准误，当前不能据细小分差判断统计显著性。

## 运行与校验

所有入口在 `scripts/`，输出在 `logs/`。Windows 使用 `D:/Git/bin/bash.exe` 执行：

```bash
bash scripts/sync-data.sh
bash scripts/check.sh
bash scripts/build.sh
bash scripts/dev.sh --host 127.0.0.1 --port 5173
```

同步脚本使用已安装的 PowerShell 7。先核验 GeoJSON 格式再替换文件，来源失败会中止，防止把错误响应当作数据。测试覆盖同年/缺失/参考年份、禁止未来快照、原始和修正版文件校验和、Qing 命名、新疆与西藏归属、满洲国和日本几何分离、15 个档案的领导人及来源、EIU 维度范围与平均值、零与缺失区分，以及苏联标识。

2026-09-18 验收：10 个边界快照的原始文件和修正版均通过哈希、要素结构和专项归属断言；15 个国家—年份档案均具有领导人文本和来源链接。浏览器逐项点击 15 个档案，实际点击 1938 年德国地图图标并看到国名、政权与领导人；1932、1966、2024 分别回退到 1930、1960、2010，严格同年模式会明确显示边界缺失。最终控制台无错误和警告，生产构建通过；本轮没有发布到远程。

## 未完成的数据范围

没有完成逐年、逐日国界重建；1932、1937、1966、1995、2020、2024 等仍缺同年几何，界面明确显示使用的较早参考快照。全球所有边界面尚未逐国补齐领导人，当前保证 15 个可选择档案均有领导人和来源；其他面会明确显示“待补充”。历史政治制度的逐维实证评分仍在继续补证。本轮提供可追溯观测，不以近似快照冒充同年几何。
