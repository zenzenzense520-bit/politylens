# ClioPatria 数据署名

本目录的派生数据来自 Seshat Global History Databank 的 [ClioPatria](https://github.com/Seshat-Global-History-Databank/cliopatria)，上游提交为 `ad28a691b7c07c1fca89d0e0636d324667d2a258`。

原始数据采用 [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) 许可。PolityLens 对 1900—2024 年时段进行筛选，并添加了殖民地、傀儡政权和实控地区的显示字段。满洲国几何使用 PolityLens 已审校的东北参考面追加，属于本项目派生修改。
